# Android frontend (planned)

**Planned stack:** Kotlin, Jetpack Compose, Android Studio, Gradle.

This folder is a placeholder for the future Android client. Start it after the Windows MVP unless there is a specific reason to prototype the Android UI earlier. UI playback/multi-output claims must be based on supported Android routing APIs and tested hardware; an app cannot assume that every connected Bluetooth endpoint can be independently targeted.

No Android Studio project is included yet.
